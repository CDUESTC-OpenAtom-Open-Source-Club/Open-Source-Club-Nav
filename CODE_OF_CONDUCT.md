# Code of Conduct

## Our Pledge

We pledge to make participation in this project respectful and open to everyone, regardless of background, identity, experience level, or viewpoint.

## Expected Behavior

- Be respectful and constructive.
- Keep technical discussion focused on evidence, tradeoffs, and project goals.
- Accept feedback gracefully.
- Give feedback in a way that helps the contributor improve the work.
- Assume good intent, but address concrete problems directly.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without explicit permission.
- Repeatedly derailing technical discussion.
- Any conduct that maintainers reasonably judge harmful to the project community.

## Enforcement

Maintainers may remove comments, close discussions, reject contributions, or restrict participation when behavior violates this Code of Conduct.

For urgent issues, contact the repository maintainers through GitHub.
