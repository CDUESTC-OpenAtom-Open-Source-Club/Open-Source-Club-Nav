# 问题排查

本文档记录当前后台移动端适配问题的排查结论、修复方向和验收检查项。该文档不再作为项目待办清单使用。

---

## 一、问题概述

后台控制台在手机端只有首页和内容管理页面基本可用，健康检测、操作日志、用户管理等页面存在明显横向溢出和表格不可读问题。

主要表现：

- 顶部导航在窄屏下横向撑开页面。
- 用户管理表格的操作列被 `minWidth` 和内联 `display:flex` 撑宽。
- 操作日志表格保留桌面最小宽度，手机端只能横向滚动。
- 健康检测表格、工具栏和统计卡片缺少完整的小屏布局约束。
- 内容管理表缺少移动端 `data-label`，无法与其他后台表格统一卡片化。
- 顶部“管理后台”身份卡仍使用单独内联样式，没有与后台卡片体系统一。

---

## 二、根因分析

### 1. 桌面表格直接进入手机端

部分后台模块仍使用桌面表格结构，且没有给表格行、单元格和操作列提供手机端替代布局。窄屏下列数过多，页面会被内容宽度撑开。

### 2. 内联样式覆盖响应式规则

后台页面存在大量内联样式，例如 `display:flex`、`gridTemplateColumns`、`minWidth`、`padding` 等。内联样式优先级高于普通 CSS，导致移动端媒体查询需要额外覆盖，维护成本较高。

### 3. 表格缺少统一移动端语义

健康检测、操作日志、用户管理已有部分 `data-label`，但内容管理表缺失，导致手机端无法用“标签 + 内容”的卡片结构展示。

### 4. 顶部导航缺少窄屏布局约束

1080px 以下导航切到顶部区域后仍按横向按钮流排布，在 375px、468px 等手机视口下容易拥挤或撑宽。

---

## 三、修复方向

### 后台导航

- 1080px 以下保留顶部导航。
- 640px 以下改为两列网格，按钮允许换行和省略。
- 内容管理子导航在手机端改为静态块，不再使用绝对定位悬浮到页面外。

### 后台表格

- 为内容管理表补充 `admin-links-table`、`admin-links-table-shell` 和 `data-label`。
- 健康检测、操作日志、用户管理、内容管理四类表格在 640px 以下统一转为卡片列表。
- 手机端隐藏 `thead`，每个 `td` 通过 `data-label` 显示字段名。
- 操作列在手机端改为明确的按钮网格，避免被内联 flex 或最小宽度撑开。

### 容器宽度

- 后台主布局、内容区、模块面板和表格壳统一设置 `min-width: 0`、`max-width: 100%`。
- 手机端表格壳取消横向滚动容器外观，改用透明背景下的卡片列表。

### 顶部与页面头部卡片

- 顶部“管理后台”身份卡改为 `admin-console-user-card` 类名体系。
- 页面头部卡片统一使用 `admin-console-pagehead` 管理 padding、背景和宽度约束。
- 手机端顶部身份卡改为纵向布局，快捷操作按钮保持两列且触控高度不低于 44px。

## 四、已验证结果

本地验证地址：`http://localhost:4000/admin`

验证视口：

- 375 x 812
- 430 x 932
- 468 x 779
- 768 x 900
- 1440 x 950

验证结果：

| 模块 | 375px | 430px | 468px | 768px | 1440px |
|------|-------|-------|-------|-------|--------|
| 顶部身份卡 | 无横向溢出，按钮两列 | 无横向溢出，按钮两列 | 无横向溢出，按钮两列 | 无横向溢出，桌面横排 | 无横向溢出，桌面横排 |
| 内容管理 | 无横向溢出，表格卡片化 | 无横向溢出，子导航不越界 | 无横向溢出，表格卡片化 | 页面不被撑宽，桌面表格保留 | 无横向溢出，桌面表格保留 |
| 健康检测 | 无横向溢出，表格卡片化 | 组件不超出卡片边框，表格卡片化 | 无横向溢出，表格卡片化 | 无横向溢出，桌面表格保留 | 无横向溢出，桌面表格保留 |
| 操作日志 | 无横向溢出，表格卡片化 | 组件不超出卡片边框，表格卡片化 | 无横向溢出，表格卡片化 | 页面不被撑宽，桌面表格保留 | 无横向溢出，桌面表格保留 |
| 用户管理 | 无横向溢出，表格卡片化 | 组件不超出卡片边框，表格卡片化 | 无横向溢出，表格卡片化 | 无横向溢出，桌面表格保留 | 无横向溢出，桌面表格保留 |

关键断言：

- `document.documentElement.scrollWidth === window.innerWidth`
- `document.body.scrollWidth === window.innerWidth`
- 手机端表格行 `display: grid`
- 手机端操作列 `display: grid`
- 后台卡片右边界未超出视口
- 验证地址保持原始路由 `http://localhost:4000/admin`
