# 05 - 后端路由模块报告

> 模块路径：`backend/router/`  
> 分析文件：`router.go`

---

## 1. 模块职责

路由模块负责：
- 注册所有 HTTP 路由
- 配置全局中间件（CORS、DB 注入）
- 定义路由分组和权限控制
- 挂载 Swagger 文档

---

## 2. 代码质量评估

### 命名规范
- ✅ 路由分组命名清晰：`publicGroup`、`authGroup`、`adminGroup`
- ✅ 路由路径遵循 RESTful 风格

### 注释质量
- ✅ 有分隔注释标明各路由组的作用
- ⚠️ 部分路由缺少功能说明

---

## 3. 架构合理性评估

### 🔴 高风险问题

1. **CORS 配置硬编码**
   - `AllowOrigins` 仅允许 `http://localhost:4000`
   - 生产环境部署时会跨域失败
   - **建议**：从配置文件或环境变量读取允许的 Origin 列表

2. **公开接口无限流保护**
   - `/register`、`/login`、`/api/admin/login` 均为公开接口
   - 没有应用任何速率限制
   - 容易遭受暴力破解和 DDoS 攻击
   - **建议**：在敏感接口上应用 `handler.RateLimit()`

3. **DB 注入方式不规范**
   - 使用 `c.Set("db", db)` 将 GORM 实例注入 Gin Context
   - Handler 中使用 `c.MustGet("db")` 获取，缺少类型安全
   - **建议**：定义自定义 Context Key 类型，提供类型安全的获取方法

### ⚠️ 中等问题

4. **路由未版本化**
   - 所有 API 直接挂在 `/api/` 下
   - 未来 API 变更时会破坏向后兼容性
   - **建议**：添加 `/api/v1/` 前缀

5. **路由注册过于集中**
   - 所有路由在一个函数中注册，函数体超过 150 行
   - 随着功能增加会越来越难维护
   - **建议**：按领域拆分路由注册函数

6. **Swagger 仅在非 Release 模式启用**
   - 条件判断 `gin.Mode() != gin.ReleaseMode` 是合理的
   - 但缺少文档说明

---

## 4. 发现的问题和缺陷

| # | 严重程度 | 问题描述 |
|---|---------|---------|
| 1 | 🔴 高 | CORS 硬编码 `localhost:4000`，生产环境跨域失败 |
| 2 | 🔴 高 | 登录/注册接口无限流保护 |
| 3 | 🟡 中 | DB 注入方式不类型安全 |
| 4 | 🟡 中 | API 路由未版本化 |
| 5 | 🟡 中 | 路由注册过于集中，单文件过长 |
| 6 | 🟠 低 | 权限中间件 `RequireRole` 在 handler 包中定义而非 middleware 包 |

---

## 5. 改进建议

1. **动态 CORS 配置**：
   ```go
   corsOrigins := strings.Split(cfg.CORS.AllowedOrigins, ",")
   r.Use(cors.New(cors.Config{
       AllowOrigins: corsOrigins,
       // ...
   }))
   ```

2. **在敏感接口应用限流**：
   ```go
   publicGroup.POST("/register", handler.RateLimit(5, time.Minute), handler.RegisterHandler)
   publicGroup.POST("/login", handler.RateLimit(10, time.Minute), handler.LoginHandler)
   adminGroup.POST("/login", handler.RateLimit(5, time.Minute), handler.AdminLoginHandler)
   ```

3. **类型安全的 DB 获取**：
   ```go
   type contextKey string
   const dbKey contextKey = "db"
   
   func GetDB(c *gin.Context) *gorm.DB {
       return c.MustGet(string(dbKey)).(*gorm.DB)
   }
   ```

4. **拆分路由注册**：
   ```go
   func registerPublicRoutes(g *gin.RouterGroup) { ... }
   func registerAdminRoutes(g *gin.RouterGroup) { ... }
   func registerMetricsRoutes(g *gin.RouterGroup) { ... }
   ```

---

## 6. 总结

路由模块的核心问题是 **CORS 硬编码** 和 **公开接口缺少限流保护**。RateLimit 中间件已经实现但没有在路由上使用是一个明显的疏忽。建议优先修复这两个安全问题。
