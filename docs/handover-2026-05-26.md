### 1.2 后台登录

登录页：

- `http://localhost:4000/admin/login`

当前真实登录链路：

- 页面提交到 `POST /api/admin/login`
- 成功后写入 `kcos_admin_session` Cookie
- `/api/admin/me` 校验当前登录态

默认后台账号：

- 用户名：`admin`
- 密码：`admin123456`

注意：

- 本地库中的 `admin` 密码哈希已经手动修正为 `scrypt` 格式
- 前端环境变量里已关闭绕过：`ADMIN_BYPASS_LOGIN=false`

### 1.3 热门仓库点击统计

已经把点击统计口径收窄为：

- 只统计 GitHub API 动态读出来的仓库点击
- 不统计友情链接、页脚、普通外链、移动菜单等其他链接点击

当前实现：

- 前端作品区点击仓库时调用 `/api/metrics/click`
- 后端把仓库 URL、仓库名、来源模块写入 `metrics`
- `/api/admin/stats` 只统计：
  - `source_context LIKE 'works-carousel:%'`
  - `target_url LIKE 'https://github.com/%'`

后台 `/admin` 热门仓库展示已改为表格，包含：

- 仓库名
- 近 7 天总点击量
- 近 7 天点击量统计图
- 当前状态（有效仓库 / 链接异常 / 待检测）

### 1.4 健康检测

健康检测页当前已改成：

- 手动按钮：`全量探测`
- 自动按钮：`自动探测`

自动探测当前实现方式：

- 前端控制台会话内定时触发
- 分钟间隔可配置
- 配置保存到浏览器本地存储

这是前端会话级能力，不是服务端 cron。
